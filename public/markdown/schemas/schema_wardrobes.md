# Noor Music: Singer Wardrobes & Clothing Dataset Schema (v1.7.0)

## 1. Schema Purpose & Overview
The **Singer Wardrobes & Clothing Dataset Schema (Draft 07)** defines the structured clothing database (`public/wardrobes.json`) for all Noor band members and official correspondent Senna Bakker.
It catalogs clothing items, garments, color palettes, materials, and footwear rules across 12 curated groups.
