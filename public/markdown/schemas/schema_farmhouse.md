# Noor Music: Farmhouse Dataset Schema (v1.0.0)

## 1. Schema Purpose & Overview
The **Farmhouse Dataset Schema (Draft 07)** defines the structured tree format (`/Farm/House/Room/Object`) for the Abcoude homestead farm, individual bedrooms, living areas, kitchen, bathroom, toilet, sauna, pool, barn animals, pasture fields, and covered parking garage.
This schema guarantees consistency across AI prompt generation for all scene actions located in or around the band's homestead.

## 2. Version History & Evolution
### v1.0.0 (2026-08-11) — Initial Farmhouse Tree Dataset Schema
- **Draft 07 URI Definition**: Formal schema identifier (`$id: https://katje.bv/schemas/v1.0.0/farmhouse.json`).
- **Hierarchical Taxonomy**: Organized by Farm -> House -> Kitchen / LivingRoom / Bedrooms / Bathroom / Toilet / Sauna / SwimmingPool / AtticStudio, Barn -> Animal Stalls, Fields -> Orchard & Canals, ParkingGarage -> Vehicles & Bikes.
